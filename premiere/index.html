Pourquoi ce laboratoire ?

Un agent logiciel est un programme qui reçoit des informations sur une situation, choisit une action pour poursuivre un objectif, puis observe ce qui a changé. Dans cet atelier, tu vas construire toi-même cette boucle de décision en Python.

TON PERSONNAGE

Voici le robot de la mission.

Tu vas lui apprendre à atteindre un colis sans heurter les obstacles. À chaque étape, le robot reçoit des informations sur son environnement. Ta fonction Python choisit sa prochaine action : avancer, tourner ou s’arrêter.

Microduck ? Microduck est un robot réel de Pollen Robotics. Dans ce laboratoire, tu pilotes seulement un personnage virtuel. Aucun robot physique n’est connecté.

UNE COMPÉTENCE PRÉCISE

Ce que tu sauras faire à la fin

  1. Lire les données transmises au programme.
  2. Écrire une fonction qui prend une décision.
  3. Tester cette fonction sur trois terrains visibles et un terrain surprise.
  4. Justifier une action grâce au journal d'exécution.

C'est la base d'un agent déterministe. Les agents utilisant un LLM et plusieurs outils seront abordés dans des modules ultérieurs : ils ne sont pas simulés ici comme s'ils existaient déjà.

02 / TA MISSIONOBJECTIF CONCRET
Ta fonction doit guider le robot jusqu’au colis.
Ton agent reçoit un dictionnaire Python appelé observation. Il contient son orientation, la direction indiquée par une balise, et une information indiquant s'il est arrivé. La balise est une information calculée par le simulateur qui suggère la direction d’un prochain déplacement. Le moteur calcule une direction sur un chemin libre, mais un obstacle apparaît réellement sur le terrain 2 entre le calcul de la balise et la décision de ton agent. La balise peut alors être périmée : tu peux l'observer dans le journal d'exécution. Tu dois donc vérifier devant_libre avant d’avancer. Tu n’as pas encore à programmer la recherche de chemin.
EXEMPLE D'OBSERVATION{"arrive": False, "orientation": "E", "balise": "S", "devant_libre": True}
Comprendre les 4 informations de l'observation
arrive
Booléen : le robot se trouve-t-il sur la cible ?
orientation
Chaîne : direction actuelle du robot (N, E, S ou O).
balise
Chaîne : direction du prochain pas sur un chemin calculé par le moteur. La balise est calculée par le moteur (recherche en largeur, BFS). Elle ne vient pas d’un LLM. Une information peut être périmée : vérifie toujours devant_libre.
devant_libre
Booléen : la case devant le robot est-elle libre ?
Écris une fonction decider(observation) qui renvoie une action : AVANCER, TOURNER_DROITE, TOURNER_GAUCHE ou STOP.
✓
Règle de réussite : le robot doit atteindre la cible puis renvoyer STOP sur quatre terrains, dont un inconnu avant le premier essai. Sur le terrain 2, un obstacle surgit devant le robot ; 16 observations de test contrôlent ses décisions lorsqu'un obstacle bloque l'avant du robot.
