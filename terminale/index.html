01 / AVANT DE CODER

Comprendre avant de programmer.

Le terrain est un graphe : chaque case libre représente un sommet, et chaque déplacement horizontal ou vertical correspond à une arête. Ton objectif est de trouver un plus court chemin, puis de vérifier qu’il reste utilisable.

01

Explorer avec une file

En BFS, les cases sont explorées dans l’ordre de leur découverte. Utilise la classe File déjà fournie : enfiler() ajoute à la fin et defiler() retire au début. Mémorise aussi les prédécesseurs. Les appels à monde.voisins sont affichés séparément des opérations réelles sur la file.

02

Conserver un plan

La classe AgentPlanificateur possède une position et un attribut plan, qui mémorise les cases du chemin restant jusqu’à la cible. Réutilise-le tant qu’aucun obstacle ne le bloque.

03

Réagir à un obstacle

Avant chaque déplacement, vérifie que la prochaine case est toujours libre. Si un obstacle bloque le plan, recalcule un chemin.

PROGRESSION GUIDÉE

Quatre étapes, pas quatre notions à découvrir d’un coup.

Commence par comprendre une grille et une file. Programme ensuite la recherche, puis seulement la mémoire du plan et le nouvel obstacle.

1 · Dessiner le grapheAvant Python

Sur une grille, une case libre est un sommet. Deux cases libres voisines horizontalement ou verticalement sont reliées. Sur le terrain « Direct », note les voisins de (0, 2).

2 · Comprendre la fileFIFO

Enfile les sommets A, puis B, puis C : le premier retiré est A. Dans le code, enfiler ajoute un sommet et defiler retire le plus ancien.

3 · Programmer BFSplanifier

Écris d’abord planifier. Pour chaque sommet sorti de la file, ajoute ses voisins non découverts. Mémorise le prédécesseur de chacun pour reconstruire un chemin minimal.

4 · Réutiliser le planpas_suivant

Stocke le chemin restant dans self.plan. Vérifie la prochaine case. Si un obstacle la bloque, recalcule le chemin avant de déplacer le robot.

DÉMONSTRATION AVANT LE CODE

Pourquoi un plan devient-il inutilisable ?

Au début, toutes les cases du couloir central sont libres. Après un déplacement, un obstacle apparaît en (2, 2) : le robot doit choisir un autre chemin.

Ce schéma explique le principe avant les tests. Les véritables déplacements seront ensuite calculés par ton programme Python.

02 / CONTRAT À RESPECTER

Deux méthodes Python à construire

planifier(monde, objectif)

Renvoie [départ, ..., arrivée] pour un plus court chemin, ou [] si la cible est inaccessible. Chaque case est un tuple de deux entiers.

pas_suivant(monde, objectif)

Mémorise la suite du trajet dans self.plan. Avant le déplacement, vérifie le prochain pas. Replanifie seulement si le plan est absent ou bloqué. Renvoie la nouvelle case ou None à l’arrêt.

Voir les opérations disponibles sur le monde

monde.voisins(case) fournit les cases libres adjacentes ; monde.est_libre(case) vérifie si une case est libre ; monde.obstacles contient les cases bloquées.

Chaque case est un tuple (x, y). Les informations du monde sont accessibles en lecture seule. Tu écris les méthodes de AgentPlanificateur ; monde te permet de consulter les cases et leurs voisins.

Indice 1 : comment construire un graphe à partir de la grille ?

Une case libre est un sommet. monde.voisins(case) renvoie les arêtes sortantes. Essaie de dessiner les voisins de (0, 2) sur le terrain direct.

Indice 2 : dans quel ordre la file BFS explore-t-elle ?

Crée une File(), ajoute le départ avec enfiler(), retire la première case avec defiler(), puis ajoute les voisins non visités. Mémorise leurs prédécesseurs.

Indice 3 : comment reconstituer puis actualiser le chemin ?

Depuis l’objectif, retrouve chaque prédécesseur pour remonter au départ, puis inverse la liste. Avant de faire un pas, vérifie que la case suivante est encore libre.
