## Déroulement élève indicatif

| Plage | Travail | Support |
|---|---|---|
| 0–3 min | Contexte, repérage C0 | Cours, partie 1. |
| 3–5 min | Prédiction individuelle P1 | Cours, partie 2. |
| 5–8 min | Première tentative guidée E1 | Laboratoire existant ou relevé fourni déclaré. |
| 8–10 min | Prédiction P2, seconde tentative E2 et comparaison E3 | Cours, partie 2. |
| 10–12 min | Explication progressive | Cours, partie 3. |
| 12–15 min | Entraînement A1–A2 | Activités, partie A. |
| 15–18 min | Transfert individuel T1–T2 | Activités, partie T. |
| 18–20 min | Bilan individuel B1 | Activités, partie B. |

Budget cible de vingt minutes, tolérance de conception jusqu’à vingt-cinq : **non mesuré**. Installation technique, préparation enseignante et remédiation supplémentaire sont relevées séparément. Ne pas supprimer le transfert ou le bilan pour faire entrer artificiellement le parcours dans vingt minutes.

## Périmètre et arrêt

Seule U01 est rédigée. Aucun nouveau cours ultérieur, ancien TP corrigé, générateur lancé, page HTML produite ou interface modifiée. Le laboratoire reste un outil d’observation préexistant ; le transfert de la porte est une situation sur papier, pas une fonctionnalité ajoutée. Aucune programmation Python n’est annoncée dans cette unité.

Les audits vérifient la suffisance des énoncés et les règles du modèle, sans se substituer à une relecture indépendante ni à un essai auprès d’apprenants. Arrêt après cette livraison : attendre la relecture humaine complète avant toute révision convenue, intégration ou extension. Aucune fusion ni aucun déploiement.
