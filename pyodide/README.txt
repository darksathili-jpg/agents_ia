Cette archive ne contient pas la distribution Pyodide (fichiers volumineux).
Lancer INSTALLER_PYODIDE.cmd sur un ordinateur connecté pour télécharger
la version 0.27.7 depuis https://cdn.jsdelivr.net/pyodide/v0.27.7/full/.
Puis copier ce dossier pyodide/ sur les machines du lycée.
Sans ces fichiers, les Workers tentent le CDN ; sans réseau, ils échouent
avec un message d'aide en français.
